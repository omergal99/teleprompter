Mobile-First PWA Teleprompter Architecture & Requirements Specification1. Executive Summary & OverviewThe Mobile-First PWA Teleprompter is a lightweight, high-performance web application designed for content creators, speakers, educators, and live presenters. The app allows users to create, format, and present scripts on mobile devices or desktops with zero friction, full offline support, and high accessibility for users of all technical levels.Key Goals:Zero Dependencies / Ultra-Fast Performance: Pure standard Web APIs (HTML5, CSS3, ES Modules / Vanilla JS or TypeScript with Vite).Static Deployment: 100% compatible with GitHub Pages hosting with zero backend required.Accessibility First: High contrast, large touch targets, intuitive iconography paired with explicit text labels (elderly/non-tech friendly).Native-Grade Mobile Features: Camera overlay, video recording, Document Picture-in-Picture (PiP) floating window, offline caching (PWA), and LocalStorage persistence.   Multilingual Out-of-the-Box: Complete Hebrew (RTL default) and English (LTR) support.2. Technical Stack & ArchitectureInspiration & ConsistencyFollowing the architecture of omergal99/paint and omergal99/notepad, the codebase is structured around clean modularity, event-driven state, and local browser capabilities.teleprompter/
├── index.html              # App entry point (semantic HTML5, accessibility markers)
├── manifest.json           # PWA manifest (standalone app, icons, orientation)
├── sw.js                   # Service Worker (offline cache strategy)

│   ├── main.css            # Base styles, CSS variables, typography

Comprehensive Feature Specifications3.1 Script Management & StorageLocal Persistence: All scripts and settings saved immediately in localStorage (with fallback to IndexedDB for media/large text).   Sample Pre-loaded Scripts: Default starter script provided in both Hebrew and English upon first launch.Script Library Drawer:Quick-select list of saved scripts with titles, word count, and estimated reading time.Duplicate, delete, rename, and export/import functionality (.txt, .json).Unlimited Text Length: Efficient DOM handling ensuring smooth scrolling even with multi-thousand-word scripts.3.2 Prompter Engine & Motion ControlsSmooth 60FPS Engine: Driven by window.requestAnimationFrame() instead of setInterval to eliminate jitter and battery drain.Dual Scrolling Directions:Top-to-Bottom (Standard upwards roll).Bottom-to-Top (Downwards roll for specialized mounting).Speed Management:Global Speed Slider: Linear speed control ranging from ultra-slow (1) to ultra-fast (100) with a balanced default at center.Per-Block Speed Overrides: Optional speed multiplier attached to specific text chunks/paragraphs (e.g., slowing down for complex sections or speeding up for transitions).Gesture & Touch Interception:Touch drag or mouse wheel movement immediately pauses auto-scroll and moves position smoothly.Auto-Resume Delay: Configurable countdown timer (e.g., 2 seconds) before auto-scrolling smoothly resumes after touch release.Start Countdown Timer: Configurable pre-roll delay (3s, 5s, 10s) with clear visual numbers on screen before scrolling starts.Elapsed Runtime Clock: Real-time stopwatch displaying exact session duration (MM:SS).3.3 Mirroring, Positioning & Visual CustomizationOptical Mirroring Transforms:Horizontal Flip (transform: scaleX(-1)): For hardware beam-splitter glass rigs.Vertical Flip (transform: scaleY(-1)): For inverted screen/monitor setups.Reading Line & Eyeline Guide:Customizable visual reading focus line/bar across the screen to maintain natural eye contact with the camera lens.Text Formatting & Layout:Font Customization: Font size slider, line-spacing, letter-spacing, and font family selection (Sans-serif, Serif, Monospace, Dyslexic-friendly).Script Width Controls: Adjustable margin percentages (e.g., script occupies 40% to 100% of screen width) to optimize eye movement for video recording.Alignment: Center, Right (RTL default), or Left (LTR default).Rich Text Accents: Bold, underline, text color highlighting per word or phrase.Color Themes:Default High-Contrast Dark: White text on pitch-black background (#000000).Inverted Light Theme: Black text on white background (#FFFFFF).Custom Palette: User-selectable custom background and text colors.3.4 Camera Overlay, Recording & Picture-in-Picture (PiP)Built-in Selfie Camera Overlay:Live camera preview underneath translucent scrolling text, allowing users to look directly into the camera lens while reading.Front/Back camera toggle for mobile devices.In-Browser Video & Audio Recording:Powered by MediaRecorder API (VP8/VP9/H.264 WebM/MP4 format).Recorded video contains only camera feed + audio (the teleprompter text is visually excluded from the output file).   In-app video playback review with direct download to device storage.Floating / Picture-in-Picture (PiP) Mode:Utilizes Document Picture-in-Picture API (or Canvas PiP fallback) to detach the teleprompter into an always-on-top floating window.   Allows reading while using native device camera apps, Zoom, Google Meet, or third-party social media video apps.3.5 Accessibility & UI/UX Design (Mobile-First)Touch-Optimized Controls:Oversized buttons with explicit icon + text labels (e.g., ▶ Play / הפעל, ⏸ Pause / השהה).Designed for single-handed operation on mobile screens.One-Tap Control Hiding:In Prompter Mode, tapping anywhere or clicking "Hide Controls" hides all overlays for distraction-free reading.Multilingual i18n Engine:Seamless instant toggle between Hebrew (he) and English (en).Dynamic layout adaptation (RTL direction for Hebrew, LTR for English).3.6 Advanced / Stretch FeaturesVoice Activation (Web Speech API):Recognize key spoken commands like "Start", "Stop", "Pause" / "התחל", "עצור", "השהה" to control scrolling hands-free.4.
